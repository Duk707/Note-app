**App Name:** Notes App

**Description:**  
A simple web application that allows users to create an account, log in, and manage their own personal notes. Each user should only be able to view and modify their own notes. The application will use Supabase for authentication and database storage and will be deployed using Netlify.

**Main Features:**

- User registration
- User login
- User logout
- View all notes belonging to the logged-in user
- Create a new note
- Edit an existing note
- Delete a note
- Protect note data so users cannot access another user's notes

**Note Data:**

- Title
- Content
- Creation date
- Last updated date
- User/owner

**Main Pages:**

- Register
- Login
- Notes Dashboard

**Technologies:**

- React
- Vite
- TypeScript
- Supabase PostgreSQL
- Supabase Auth
- Git/GitHub
- Netlify
- Antigravity IDE

**Definition of Done:**  
A user can register, log in, create/read/update/delete their own notes, log out, refresh the browser without breaking the application, and use the finished deployed application through Netlify.
