## Project

Notes App

## Purpose

Build a simple web application that allows authenticated users to create,
view, edit, and delete their own personal notes.

This project is being developed for an Engineering Design 2 assignment
using AI-assisted software development.

## Technology Stack

- React
- Vite
- TypeScript
- Supabase PostgreSQL
- Supabase Authentication
- Git and GitHub
- Netlify

## Development Rules

1. Follow the requirements defined in PLAN.md.

2. Keep the application simple and focused on the assignment requirements.

3. Do not add features that are not requested.

4. Use Supabase for authentication and database functionality.

5. Do not create a custom backend unless it becomes technically necessary.

6. Users must only be able to access their own notes.

7. Use Supabase Row Level Security to protect user data.

8. Never place passwords, service-role keys, or other private secrets in
   frontend source code or Git.

9. Environment configuration should use environment variables.

10. Do not commit .env or .env.local files.

11. Use TypeScript where possible.

12. Keep authentication, database access, and UI logic reasonably separated.

13. Handle errors instead of silently ignoring them.

14. Add loading states where network/database operations take time.

15. Test each major feature before moving to the next implementation step.

16. Do not remove security or validation checks just to fix an error.

17. Avoid unnecessary dependencies and unnecessary architectural complexity.

18. Before making major changes, explain what will be changed.

19. After completing a feature, summarize what changed and how it was tested.

20. Do not begin future build stages unless requested.
